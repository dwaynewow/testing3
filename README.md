# IVA AMU

Адаптивный демонстрационный магазин браслетов из натуральных камней.

## Открыть без установки

Скачайте репозиторий через **Code → Download ZIP**, распакуйте архив и откройте файл **ОТКРЫТЬ-САЙТ.html**. В нём уже находятся код, шрифты, фотографии и актуальная бирюзово-песочно-абрикосовая палитра.

## Запуск для разработки

Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev -- --port 5173
```

Сборка: `npm run build`. Просмотр сборки: `npm run preview`.

## Возможности

Глубокая бирюзовая, песочная и абрикосовая палитра ювелирного магазина, поиск по названию и камню, навигация по категориям, каталог с фильтрами, избранное, карточка товара и размер запястья, локальная корзина с количеством, скачивание списка выбора, подбор по анкете, мобильная навигация, вопросы об уходе. Шрифты и изображения локальные; приложение не требует API или секретов.

## До запуска продаж

Товары, изображения и цены демонстрационные. Нужны реальные фотографии, цены, контакты, сведения о продавце, условия доставки и возврата. Оплата и отправка заказов не подключены; скачивание сохраняет текстовый список на устройстве пользователя. Корзина и избранное хранятся в localStorage.

Логотип подготовлен из предоставленного изображения с удалением фона через генератор изображений. Для точной печатной версии рекомендуется заменить его оригинальным SVG/PNG бренда.
